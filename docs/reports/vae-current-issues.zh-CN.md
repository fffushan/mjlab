- **已确认缺陷**：代码或 CPU 反例直接支持。

- **P2**：影响诊断、异常路径或资料管理，按使用范围修复。

VAE 是变分自编码器。DAgger 是在学生访问状态上查询教师动作的数据聚合方法。
本阶段目标是教师动作保真度，不是直接优化奖励。

### F1 · P1：数值控制配置没有完整进入检查点契约

**状态：已确认。CPU 反例已复现。**

位置：

- `model.py:240–252,274–289`
- `trainer.py:126–143,451–453`
- `checkpoint.py:299–307,426–434,536–540,1230–1234`

`numerical_controls=True` 控制两种行为：

1. 模型将对数方差限制到 `[-10,10]`。
2. 训练器将梯度范数限制到 `1.0`。

模型额外状态和直接检查点训练契约没有保存此选项。
模型专用加载器按默认值 `False` 重建模型。
训练器还允许模型与训练配置使用不同的数值控制值。

**复现结果：**

- 受控模型和训练器可以加载到非受控实例，直接恢复 API 没有拒绝。
- 将有限的对数方差头输出固定为 `200`。
- 原模型输出 `10`，重建模型输出 `200`。
- 原模型的固定噪声采样有限，重建模型的采样产生非有限潜变量。
- 此反例中的均值潜变量动作完全一致。

**影响范围：**

- 采样评估不再忠实于训练配置。
- 直接恢复可能改变数值策略。
- 当前均值 ONNX 动作不使用方差，因此不能据此认定动作导出损坏。
- 多教师 CLI 另检查 `resolved_config`。该检查不能修复模型专用加载器。

**修复要求：**

- 保存一个明确的数值控制契约。
- 所有模型加载器恢复该契约。
- 默认拒绝模型与训练器的选项冲突。
- 兼容逻辑必须区分旧非受控模型和新受控模型。
- 不能将所有缺字段的模型一律视为 `False`。当前受控检查点也缺少此字段。
- 对来源不明确的模型，要求显式兼容决定。

**回归验证：**固定超出边界的对数方差和采样噪声，比较保存前后采样动作。
验证直接恢复在配置冲突时先拒绝，再确认活跃状态没有变化。

## 5. 采集与监督预算问题

**状态：算术与代码已确认。用户将其列为需要修正的设计问题。质量因果未证明。**

30 教师运行参数：

```text
新采集行数 I = 28,672 × 32 = 917,504 / 轮
有效批次 B = 4,096 × 8 = 32,768 / 更新
训练抽样数 T = B × 4 = 131,072 / 轮
回放容量 C = 1,966,080
T / I = 1/7
平均保留轮数 C / I ≈ 2.14
```

`1/7` 是抽样次数与新行数的比值，不是精确的独立样本使用比例。
普通采样可以重复行，也可以抽到旧行。
FIFO 不检查数据是否参与过训练。因此，许多行可能在零次训练后被移除。
全部新行用于归一化统计，但只有抽样行直接贡献教师重建损失和梯度。

扩大教师集合，但固定每轮优化预算，会减少每个动作的监督曝光。
近似平均抽样数从 8 教师的 `16,384` 降到 30 教师的 `4,369`。

**限制：**高相关普通样本不一定需要全部训练。低比值本身不证明欠拟合或摔倒原因。
精确独立行曝光率尚未测量。

### 拟采用预算

| 更新数 / 轮 | 有效批次 | 总抽样数 / 轮 | 总抽样 / 新行 |
|---:|---:|---:|---:|
| 4，当前 | 32,768 | 131,072 | 0.143 |
| 14，匹配旧近似比值 | 32,768 | 458,752 | 0.500 |
| 16，讨论候选 | 32,768 | 524,288 | 0.571 |
| 28 | 32,768 | 917,504 | 1.000 |

增加有效批次和增加更新次数不等价。
大批次在同一权重上平均更多梯度。更多更新在变化后的权重上重复求解。
Adam 历史与梯度裁剪也随更新次数变化。

首轮候选是有效批次保持 `32,768`，更新数增至 `16`。
这是待验证建议，不是当前默认设置，也不是已证明的最佳值。

## 6. 困难状态保护池：已选方向，执行路径仍未完成

相关实现：`coverage_policy.py`、`coverage_storage.py`、`coverage_collector.py` 等。
契约：[困难状态 P0 配置](../plans/beyondmimic_vae_difficult_state_coverage_p0_contract.yaml)。

保护池必须同时提供：

1. **保留策略**：按动作、阶段、严重度和来源家族保留困难样本。
2. **抽样份额**：为保护样本分配明确的监督预算。
3. **标签时序**：从正确的执行前或复位前输入查询冻结教师。
4. **数据隔离**：同一轨迹及其教师分支不跨训练与留出集。

原契约提出保护容量占 `20%`、保护抽样占 `20%`。
来源类别包括学生困难状态、教师延续分支和有限的失败后状态。
首轮比例需要验证，不是最优值声明。

### 不能混淆的两件事

- 增加缓冲区容量不自动增加每行平均训练次数。
- 增加保护抽样会占用总训练预算，不是额外免费样本。

例如，16 次更新共抽样 `524,288` 次。
若保护比例为 `20%`，约 `104,858` 次用于保护池，约 `419,430` 次用于近期回放。
实际整数分配按每动作的舍入规则执行。

### 当前不能宣称正式可用

- 公共 `_train` 入口没有接通 `--coverage-policy`。
- 下层组件存在，不代表真实采集完整可执行。
- `require_coverage_execution` 仍拒绝启用的执行请求。
- 来源、终止状态对齐、恢复后的下一步物理一致性和预算仍有未测量项。
- F4、F5 会影响来源及覆盖统计。必须先修复。

### 损失保持不变

近期和保护样本使用相同的教师动作重建损失与 KL 系数。
不增加成功/失败专用损失乘数，也不增加关节专用损失权重。
保护抽样改变训练分布，必须如实记录。
它不证明教师有能力从这些状态恢复。

## 7. 其他方法与验证风险

### M1：`coverage=1.0` 不是困难状态覆盖

`balanced_storage.py:310–312` 定义：

```text
coverage = retained_rows / motion_capacity_quota
```

它仅说明分区是否装满。
动作阶段、严重度、状态组合和硬件失败区域需要独立统计。

### M2：最终检查点不是最佳检查点

30 教师运行使用 `evaluate_every: 0`。
训练没有使用留出集选择最佳模型。
历史固定状态检查点扫描对成功与失败分层给出不同最优迭代。

需要固定、按轨迹家族隔离的留出集。
定期报告普通状态和困难状态保真度。
不能从一个失败片段选择普遍最佳迭代。

### M3：评估平均值按片段等权

`aggregate_evaluation_metrics()` 对片段均值等权平均，不按控制步数加权。
短失败片段和长成功片段可能具有相同权重。
源代码有意采用该规则，因此它不是单纯的除法错误。

报告需要同时说明片段数、控制步数、失败数、删失数和聚合分母。
比较模型时可另外报告按控制步加权的指标，但不能静默改变历史指标语义。

### M4：历史潜变量敏感性不能代替当前学生验证

历史模型固定集上，潜变量置零使原始动作 RMS 改变 `0.21992906130949244`。
片段内打乱潜变量使其改变 `0.2838971100898987`。

这排除该固定集上完全忽略潜变量的情况。
它不证明当前 30 教师模型的潜空间容量、平滑性或控制效果。
替换潜变量可能超出访问分布。需要当前模型自己的诊断。

### M5：论文适配不能称为精确复现

当前 X2 方案有以下明确差异：

- 使用 `68/99` 无状态估计输入，省略锚点位置误差和线速度。
- 相关控制率为 `50 Hz`，论文扩散相关跟踪阶段为 `25 Hz`。
- 使用在线 Welford 统计与有界近期 FIFO。
- 主要运行使用 8 个累积微批次，论文表 S6 为 15。
- 默认均值推理、采样训练是明确工程选择。
- 对称增强方向已经关闭。

不要重新开放不可观测的 `gravity_twist` 部署方案。
不要将独立公开复现项目的工程选择称为论文作者的已公开实现细节。

1. 修复 F1、F2，并验证所有保存、加载和分发路径。
2. 修复 F3，明确旧布局迁移与新布局兼容规则。

6. 验证困难状态时序、教师标签、家族隔离和真实保留策略。
7. 预先固定对照条件、更新预算和留出指标。
8. 执行更多更新与保护抽样的受控试验。
