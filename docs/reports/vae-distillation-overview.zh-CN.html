01目标与边界

变分自编码器（VAE）用潜变量连接参考意图和当前控制。每个教师策略擅长一个参考动作。

教师策略由近端策略优化算法（PPO）训练。

蒸馏训练一个共享学生策略。学生学习各教师在相同输入状态下的动作。

教师：提供监督

每个教师保留自己的权重和观测归一化统计。蒸馏不更新教师。

学生：共享控制模型

所有动作共享一个编码器和一个解码器。动作选择由参考输入表达。

潜变量：连接意图与控制

32 维潜变量传递动作意图。解码器结合当前状态，产生关节指令。

本阶段不是 PPO。
学生通过教师动作标签训练。训练不计算策略优势、价值损失或 PPO 比率。环境奖励用于诊断，不是 VAE 的训练目标。

不是精确的论文复现。本方案保留论文的模型结构和主要损失。X2 使用无状态估计输入，并保留 50 Hz 控制。论文相关阶段使用 25 Hz。

不是原始动作序列的压缩。编码器接收当前参考信息。解码器输出当前一步动作。输入中的锚点误差来自当前机器人状态。因此，不能仅从动作文件预先生成固定潜变量序列。

当前实现已有范围内验证拟采用 / 未执行限制 / 未验证

02输入与输出：68 → 32，32 + 99 → 31

接口组成维度用途
编码器参考输入参考关节位置 31 + 参考关节速度 31 + 锚点方向误差 668表达当前动作意图和方向偏差
解码器当前状态输入根部投影重力 3 + 陀螺仪 3 + 相对关节位置 31 + 关节速度 31 + 上一次执行动作 3199表达当前状态和控制历史
潜变量编码器输出的均值，或训练时的高斯样本32传递参考意图
输出动作31 个归一化关节位置指令31送入现有动作处理和电机控制链
教师观测参考 q/dq 62 + 锚点方向误差 6 + 陀螺仪 3 + 相对 q 31 + dq 31 + 上一次动作 31164按教师的原始观测契约生成标签

归一化器按训练数据的均值和标准差缩放输入。教师使用各自的固定统计。学生使用两个独立的共享统计。

锚点是跟踪任务选定的参考刚体。当前 X2 教师使用 torso_link。6 维方向误差采用旋转矩阵的前两列。

投影重力使用根部坐标系。陀螺仪使用教师约定的传感器坐标系。根部、锚点和传感器不是同一概念。

数据对齐要求
教师输入和学生输入必须对应同一次观测快照。共享的关节和陀螺仪字段来自同一缓存。不能为两个模型分别重采样噪声。投影重力是学生增加的直接状态输入，其硬件估计误差需要单独验证。

q_target = q_default + action_scale ⊙ action

输出不是力矩，也不是精确轨迹目标。位置指令经过比例—微分（PD）控制形成力矩。动作尺度、关节顺序、默认姿态和 PD 增益都属于部署契约。

03模型结构与训练目标

L_recon = mean_rows [ Σ_j (a_student,j − a_teacher,j)² ]

L_KL = mean_rows [ −½ · Σ_k (1 + log σ²_k − μ²_k − exp(log σ²_k)) ]

L_total = L_recon + 0.01 · L_KL

重建损失要求学生复现教师动作。KL 损失约束高斯潜变量分布，使其接近标准正态分布。

代码先对 31 个动作维度求和，再对样本求平均。KL 项先对 32 个潜变量维度求和，再对样本求平均。

训练使用采样潜变量。默认评估和导出使用均值潜变量。两者不是相同的推理模式。

当前优化器是 Adam。学习率为 5e-4。启用 numerical_controls 后，模型限制对数方差至 [-10,10]，训练器限制梯度范数至 1.0。

当前限制
数值控制选项在模型保存和重建边界存在缺陷。采样评估可能丢失方差限制。默认均值推理不使用方差，但这不能证明采样路径正确。详见同目录的 当前问题记录。

04DAgger：在学生访问的状态上查询教师

仅模仿教师轨迹，学生容易只见到“教师走对的状态”。学生执行时产生偏差，输入分布也会改变。

数据聚合方法（DAgger）让学生执行动作，再让教师为学生访问的状态提供标签。教师标签表达“此时教师会做什么”。标签不等于已经执行的动作。

① 启动采集

教师先执行一段轨迹，形成初始回放。学生随后开始接受监督更新。

② 学生采集

学生执行动作。教师在同一执行前快照上提供标签。自动复位和参考跳转建立新的片段边界。

③ 归一化更新

两个学生归一化器仅使用新采集数据更新一次。采集和评估期间不修改统计。

④ 监督更新

训练器从回放取样。编码器根据当前权重重算潜变量。训练不使用旧模型缓存的潜变量。

失败前状态与终止状态不同。
普通采集保留有效的失败前标签。环境自动复位可能移除刚到达的终止状态。保留终止状态需要复位前采集和重新标注。相关路径必须验证时序。

05采集量、有效批次与优化次数

采集预算和训练预算独立。训练器不会自动遍历全部新数据。

每轮新采集
917,504

28,672 个环境 × 32 个控制步

每次优化有效批次
32,768

4,096 个样本 × 8 个累积微批次

每轮训练抽样
131,072

32,768 × 4 次 Adam 更新

一个样本可以重复参与训练。另一个样本可能一次也没有参与训练。先进先出（FIFO）回放只按年龄和容量移除数据。

扩大教师集合，但保持优化次数不变，会减少每个动作的监督抽样量。当前 30 教师运行每轮约有 4,369 次抽样分配给每个动作。旧 8 教师运行每轮约有 16,384 次。

解释边界
低抽样比例不自动证明训练失败。相邻样本可能高度相似。模型也可以从少量样本泛化。但困难状态可能较少见。仅采集到它，不保证它参与过梯度计算。

大批次和多次更新不是等价操作

方式有效批次每轮更新数每轮抽样数区别
当前配置32,7684131,072基线
增大微批次至 8,19265,5364262,144同一权重上平均更多梯度；显存需求增加
增大更新数至 832,7688262,144模型先更新，再用新权重计算下一次梯度
拟试验：16 次更新32,76816524,288抽样预算为当前的 4 倍；未验证收益

损失对样本取平均。因此，大批次通常减小梯度抽样噪声，而不是成倍放大更新。多次 Adam 更新会多次改变参数、梯度历史和裁剪行为。

增大微批次并减少累积次数，可保留相同有效批次。它主要改变显存和吞吐。实际速度必须测量。

动作均衡、阶段均衡和困难状态保护不同

动作均衡决定每个参考动作的环境行数、回放配额和训练抽样份额。环境行在普通复位后仍使用分配的动作。

阶段均衡是可选抽样功能。它把参考帧分为若干区间，让已有样本的各非空区间获得较均衡的训练曝光。

阶段均衡不改变 FIFO 移除规则，也不保护较旧的困难状态。困难状态保护需要独立保留与抽样策略。

检查点包含模型、优化器、归一化统计、回放、计数器、随机状态和契约。回放通常占主要体积。

恢复训练不恢复完整物理仿真状态。环境重新启动，并使用新的片段命名空间。不能声称恢复后是逐位相同的连续轨迹。

07导出、在线推理与后续扩散接口

当前 VAE 跟踪推理：
参考 q/dq + 当前锚点方向误差 → encoder.onnx → μ32
μ32 + 同一快照的当前状态99 → decoder.onnx → action31

后续扩散接口：
扩散模型生成 z32 + 最新当前状态99 → 同一个冻结 decoder → action31

导出模型采用开放神经网络交换格式（ONNX）。两个推理图内置学生归一化参数。调用方输入原始契约值，不再重复归一化。

共享学生只需要一套编码器和解码器。多教师包另外保存每个成员的参考表、动作契约和一致性记录。

选择成员时更换参考动作。默认解码器不接收成员 ID。图的批次大小必须按导出接口执行；历史部署图固定为单样本。

潜变量接口的意义
后续扩散模型可以替代编码器，提供潜变量。解码器仍使用最新当前状态。本文不介绍扩散模型训练，也不把扩散的性能优化视为 VAE 优化。

08拟采用：困难状态保护池 + 更多优化更新

已选择改进方向未接通并验证为正式训练路径

目标是保留少见的困难状态，并让它们持续参与监督。仅增大普通 FIFO 容量不能保证训练曝光。

  • 保留：困难样本不随普通近期 FIFO 一起快速消失。保护池仍有界，按来源家族等条件替换。
  • 抽样：每个动作分配固定的保护抽样份额。保护池不足时必须明确记录回填或跳过规则。
  • 一致损失：近期和保护样本使用相同教师动作重建损失与 KL 系数。
  • 独立评估：同一学生轨迹及其教师分支归入同一数据家族。不能拆分到训练集和留出集两侧。

讨论中的首轮候选是：有效批次保持 32,768，每轮更新增至 16，保护抽样占 20%。

此时每轮有 524,288 次总抽样。约 80% 分配给近期回放，约 20% 分配给保护池。保护抽样占用总预算，不是额外免费抽样。

执行前要求
先修复配置恢复、旧回放兼容和逐行来源记录。再接通公共入口。验证真实采集、保留策略、恢复一致性和预算。当前代码中的组件存在，不等于正式训练可用。
